# Configuration

Configure **Geo Maps**: via the Craft Control Panel, or using a config file for advanced configuration.

## Services & Tokens

Below is a list of the various services supported by Maps, along with links on how to obtain their tokens.

### Map Tiles & Geocoding

| Service | Token Required? |
|---|---|
| [Google](https://cloud.google.com/maps-platform/#get-started) | Yes |


::: tip Google Maps
You will need to enable the **Maps JavaScript API** and **Places API** for map tiles, and the **Places API** and **Geocoding API** if using Google for the Geo service.
:::


## CP

You can access the Maps settings in the Craft CP by navigating to **Settings → Geo Maps** in an environment where `allowAdminChanges` is set to `true`.
